# Sea-Doo — комплект для боевого сервера, 7 ноября 2026

Рабочая модель: `BPC_SeaDooQuadPrototype` на базе RIS. Движение проверено пользователем на локальном выделенном сервере. Диагностика удалена. Урон деталям при погружении и таймер разрушения в воде отключены. Клиентская версия содержит восстановленные брызги корпуса и две кормовые струи.

Лодочная версия `BPC_SeaDooGTISE130` выведена из эксплуатации и удалена из клиентского каталога. Для спавна используйте:

```text
#SpawnVehicle BPC_SeaDooQuadPrototype
```

## Установка

1. Остановите боевой сервер и сохраните копию его `SCUM/Saved/SaveFiles` и заменяемых файлов `SCUM/Content/Paks/~mods`.
2. Скопируйте четыре файла из `Server` в серверную папку `SCUM/Content/Paks/~mods` с заменой. Серверный реестр подготовлен из действующего реестра боевого сервера, скачанного 7 ноября 2026. Сохранены 128703 записи остальных ассетов, импортированы 12 записей рабочей версии Sea-Doo. Если серверный реестр после подготовки комплекта обновлялся другими модами, его нужно объединить заново.
3. Уберите `pakchunk926-SeaDooNativeBoatInput_P.pak` и одноимённый `.sig`, если они остались в установке. Удалите старые конкурирующие реестры тестовых сборок Sea-Doo. В комплекте используется действующее серверное имя `zzzzzzzzzzzzzzzz_pakchunk999-ModsRegistry_9999_P.pak`.
4. Игрокам требуется актуальная клиентская версия из GitHub/лаунчера. Для ручной установки используйте четыре файла из `Client` при закрытой игре. Клиентский и серверный PAK различаются визуальными эффектами; выбирайте файлы по папке назначения.
5. Запустите сервер, подключитесь и проверьте посадку, движение вперёд/назад, повороты и эффекты. Новый серверный реестр подготовлен по текущему боевому комплекту, но его загрузка на боевом сервере ещё не проверена.

Контрольные суммы файлов находятся в `manifest.json`. Сохранения и учётные данные в архив не включены.
