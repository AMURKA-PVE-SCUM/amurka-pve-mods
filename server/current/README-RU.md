# Актуальное обновление AMURKA — 7 ноября 2026

## Сервер

Папка `Server` содержит десять файлов: рабочий серверный Sea-Doo, актуальный KatanaPack, AmurkaRebellion, AmurkaAxe, их `.sig` и объединённый серверный реестр.

Установите все десять файлов в `SCUM/Content/Paks/~mods` при остановленном сервере. Сохраните резервную копию заменяемых файлов и сохранения. Остальные установленные серверные моды остаются на месте.

Серверный реестр подготовлен на основе действующего реестра боевого сервера, дополнен 12 записями рабочего Sea-Doo и 67 ассетами новых оружейных PAK. Ранее существовавшие 128715 записей сохранены. Лодочный прототип Sea-Doo исключён. Не используйте тестовые `pakchunk926-SeaDooNativeBoatInput_P.pak` и `.sig`.

## Клиент

Игрокам рекомендуется обновление через актуальный GitHub-каталог лаунчера. Он включает 64 файла, совпадающих с рабочей игровой папкой.

Для ручного дополнения уже обновлённого клиента папка `Client` содержит шесть файлов: два новых оружейных PAK, их `.sig` и объединённый клиентский реестр с `.sig`. Копируйте при закрытой игре.

## Состав новых PAK

AmurkaRebellion содержит классы `AmurkaRebellion`, `AmurkaPan`, `AmurkaScythe`. AmurkaAxe содержит `AmurkaAxe`, `AmurkaCleaver`. Все пять классов оружия и их EntitySetup зарегистрированы; зарегистрированы также включённые модели, материалы, текстуры, таблицы урона и профиль персонажа.

Рабочая команда для гидроцикла:

```text
#SpawnVehicle BPC_SeaDooQuadPrototype
```

Контрольные суммы находятся в `manifest.json`. Клиентская и серверная версии Sea-Doo и реестров различаются по назначению. Сохранения, пароли и журналы игроков в комплект не входят.
